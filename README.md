Orçamento para Festa — Casa Maria do Bolo e Salgados

Sistema de orçamento interativo via terminal para festas, desenvolvido em Python como Projeto Integrador.

O programa exibe um menu de itens típicos de festa (bolos, salgados, doces, refrigerantes e outros),
permite que o usuário informe quantidades e preços, e ao final gera um resumo completo com o total a
pagar.
 Pré-requisitos- Python 3.x instalado na máquina- Nenhuma biblioteca externa necessária
 
 Como executar
 
python orcamento_festa.py

 Como usar
1. Ao iniciar, o menu de itens será exibido
2. Digite o número da opção desejada e pressione Enter
3. Informe a quantidade e o preço quando solicitado
4. Repita para todos os itens que desejar adicionar
5. Digite 0 para finalizar e exibir o resumo do orçamento
